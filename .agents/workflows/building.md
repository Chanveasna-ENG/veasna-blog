---
description: When building any feature, it must follow these steps.
---

1. First Call the @interrogator to questions and how to handle until you got complete understand of the code.
2. Second Call the @tblueprint to create a blueprint and test cases of edge cases of the feature.
3. Third Call the @implementer to build the feature.
4. Fourth Call the @auditor to audit the code if it is up to the standard.
5. If there any problem flagged by the @auditor then we will call the @interrogator and perform 1, 2, 3, 4, 5 again.
